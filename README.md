# WebGL Sierpinski Carpet

WebGL을 활용하여 재귀적 프랙탈 구조인 **시에르핀스키 카펫**을 렌더링하고, 분할 횟수 및 색상을 실시간으로 제어할 수 있는 웹 그래픽스입니다.

---
## 주요 기능
1. **재귀적 분할 횟수 제어**
    - 0단계부터 5단계까지 슬라이더를 통해 실시간으로 재귀 깊이를 조절합니다.
    - 단계 변경 시 $3 \times 3$ 분할 중 중앙 1개를 제외한 8개 영역에 대해 정점 좌표를 재계산하여 버퍼를 갱신합니다.


2. **실시간 색상 제어**
    - **카펫 색상** : WebGL 셰이더의 `Uniform` 변수를 갱신하여 도형 색상을 즉시 변경합니다.
    - **배경 색상**: `gl.clearColor` 설정을 통해 캔버스 뷰포트 배경색을 유연하게 제어합니다.
3. **순수 WebGL 파이프라인 기반 렌더링**
    - Native WebGL API만으로 버텍스/프래그먼스 셰이더 및 VBO를 직접 제어합니다.
